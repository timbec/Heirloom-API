# CLAUDE.md

FastAPI backend for Heirloom. Replaces the Heirloom parts of the old Laravel app. Read `../CLAUDE.md` for what Heirloom is and `../docs/backend-port.md` for the full plan (API contract, prompts, known bugs, build order). Progress is tracked in `../tasks/todo.md`.

## Running locally

Postgres 17 runs natively via **Postgres.app** (port 5432, your macOS user, no password). Start it from the menu bar; quit it when you're done. No Docker.

```bash
uv sync                                   # install deps
cp .env.example .env                      # first time only; fill in GROQ_API_KEY
uv run uvicorn app.main:app --reload      # http://localhost:8000/api/health, docs at /api/docs
uv run pytest                             # tests (always use the heirloom_test database)
uv run ruff format . && uv run ruff check .
uv run alembic upgrade head               # apply migrations to the dev database
uv run alembic revision --autogenerate -m "add x"   # after changing a model; review the file
uv run python -m app.cli create-user --email you@example.com --name "You" --admin   # prompts for password
uv run python -m app.cli set-password --email you@example.com
```

Databases: `heirloom` (dev) and `heirloom_test` (tests). If they're missing:
`createdb heirloom && createdb heirloom_test` (psql tools are in `/Applications/Postgres.app/Contents/Versions/latest/bin`).

## Models and migrations

- Models live in `app/models/` (SQLAlchemy 2, typed, async). Add new ones to `app/models/__init__.py` so Alembic sees them.
- The API's "session" is `InterviewSession` in code (table `sessions`), to avoid confusion with DB sessions.
- Ownership flows from `Subject.user_id`; sessions, transcripts, turns and narratives reach the user through the subject. Deletes cascade in the database (`ON DELETE CASCADE`), and relationships use `passive_deletes=True`.
- Async gotcha: never touch an unloaded relationship (it raises `MissingGreenlet`). Load what you need with `selectinload(...)`.
- Every migration is autogenerated, then reviewed by hand. Alembic runs ruff on new files. `test_migrations_match_models` fails if a model changes without a migration.
- Tests build the schema from the migrations and round-trip downgrade/upgrade once per run. Each test runs inside a transaction that's rolled back (the `db` fixture in `tests/conftest.py`).

## Auth

- `POST /api/auth/login` returns `{token, user}`. A failed login returns Laravel's 422 `{message, errors.email}`. Limited to 5 attempts per IP per minute (in memory, single process; move to Redis in step 10).
- Tokens are 40 random characters; only their sha256 is stored (`api_tokens`). `CurrentUser` / `CurrentToken` in `app/api/deps.py` protect routes (401 `{"message": "Unauthenticated."}`).
- `POST /api/auth/logout` revokes the current token; `GET /api/auth/me` returns the user.
- No public sign-up yet: create users with the CLI. In tests, use the `user` and `auth_headers` fixtures.

## App endpoints (`/api/heirloom/v1`)

- Routers in `app/api/` are mounted on `v1_router` in `app/api/__init__.py`. Request/response models live in `app/schemas/`.
- Lists return `{data: [...]}` (`ListResponse`), unpaginated. The frontend resolves subject slugs from the full list.
- Load owned resources with `get_owned_subject` / `get_owned_session` (`app/api/ownership.py`): 404 if missing, 403 `{"message": "Forbidden"}` if another user's. Referencing someone else's subject in a request body gets the same 422 as a missing one.
- Optional text fields use `OptionalText` / `OptionalShortText` (`app/schemas/common.py`): trimmed, with `""` turned into `null`, as Laravel did.

## AI calls

- `app/services/groq.py` (`chat_completion`) is the only place that talks to Groq. It raises `AIError` for anything unusable. Base URL, key and model names come from settings.
- `app/services/narratives.py` holds the narrative prompt (ported verbatim from Laravel) and `generate_narrative`. Every attempt is saved as a new `Narrative` row (history is kept), failures included, with `error`, `model` and `session_ids`.
- Tests pin fake `GROQ_*` settings in `tests/conftest.py` and fake the HTTP calls with respx (`https://groq.test/...`). They never use the real key.

## Conventions

- Every route lives under `/api`. Keep the existing contract (`docs/backend-port.md` §4) so `heirloom-web` works unchanged.
- Errors are Laravel-shaped: `{message}` and, for validation, `{message, errors}`. See `app/errors.py`. The frontend reads `message`.
- Multi-tenant: every user-facing query is scoped to the current user. Only the admin panel sees across users (`users.is_admin`).
- AI provider settings and model names come from env (`app/config.py`), never hardcoded.
- Tests use pytest-asyncio (auto mode) with an httpx `AsyncClient` fixture; fake Groq with respx.
